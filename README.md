# GFG DSA — 400 Problems in 1 Year Roadmap

> Goal: Solve **400 GeeksforGeeks (GFG) DSA problems in 12 months**, from beginner to advanced, and maintain every solution on GitHub.

GFG currently provides a large topic-wise practice collection, including Arrays, Strings, Searching, Sorting, Hashing, Linked Lists, Trees, Graphs, Greedy, Dynamic Programming, Trie and more. This roadmap uses those topic categories to create a structured 400-problem progression.

# 🧠 Problem-Solving Method

For every GFG problem:

1. Understand the problem.
2. Write down the input and output.
3. Identify the topic/pattern.
4. Think of brute force.
5. Find the optimized approach.
6. Dry run with an example.
7. Code in C++.
8. Test edge cases.
9. Analyze time complexity.
10. Analyze space complexity.
11. Write the key learning.
12. Add the solution to GitHub.

# 🔥 Rules for the 400-Problem Challenge

- Don't copy solutions immediately.
- Give yourself **30 minutes** before checking hints.
- After seeing a solution, close it and code again yourself.
- Re-solve difficult problems after 3–7 days.
- Maintain GitHub regularly.
- Track patterns, not just problem counts.
- Prioritize understanding over speed.
- Take a weekly contest or timed practice session when possible.
